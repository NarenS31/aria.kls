# ARIA Sample Learning Report

> Demonstration artifact only. Jordan Rivera is a fictional student profile,
> and the observations below are derived from synthetic ARIA data.

## Student overview

| Field | Demonstration value |
|---|---|
| Student | Jordan Rivera |
| Grade | 10 |
| Learning profile | ADHD-Inattentive |
| Preferred approach | Visual explanations |
| Focus window | Approximately 15 minutes |
| Current subjects | Geometry, chemistry, and JavaScript |

## What appears to be working

- Visual representations support geometry reasoning.
- Step-by-step explanations reduce overload in chemistry.
- Concrete analogies make JavaScript concepts easier to connect.
- Short work periods provide a clearer starting point than open-ended study
  sessions.

## Areas that may need support

- Geometry proofs can trigger uncertainty about which property to use first.
- Stoichiometry and balancing equations may require smaller intermediate steps.
- JavaScript callbacks and asynchronous behavior benefit from concrete traces
  of execution order.
- Longer tasks should be divided before attention begins to drop.

## Suggested accommodations

1. Show a diagram or worked visual structure before asking Jordan to begin a
   geometry proof.
2. Break chemistry problems into one visible transformation at a time.
3. Use short code traces and real-world analogies when introducing asynchronous
   JavaScript.
4. Ask Jordan to state a plan before beginning a multi-step task.
5. Offer a brief reset after approximately 15 minutes of sustained work.

## Example ARIA intervention

**Likely state:** Confused

**Evidence:** The student names familiar information but cannot identify the
next operation.

**ARIA asks:** “What part still feels clear? Start there, then name the first
point where the path gets fuzzy.”

## Interpretation note

ARIA state estimates are working hypotheses, not diagnoses. This sample shows
the intended report structure and should not be interpreted as evidence about a
real student or as a validated classroom outcome.
